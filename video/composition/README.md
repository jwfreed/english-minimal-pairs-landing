# Soundwise English launch composition

Editable 20-second, 1920×1080, 30fps source; no narration. See
[../README.md](../README.md) for the authoritative install, render, finishing,
localization and validation workflow. From the website root, use
`npm run video:render -- --locale en`; outputs go to ignored staging.

For direct preview/check from this directory, first install the authoring tools
at the website root with `npm run video:install`, then `npm run dev` or
`npm run check`. The local CLI is pinned to 0.8.186. The current source owns all
fonts/media/runtime assets it serves; no app files are read. Original creative
context and reviews in `../history/` are historical, not active instructions.
